# 💻 Portfólio Profissional - Nati Peralta

Portfólio oficial desenvolvido para apresentar minha trajetória, habilidades técnicas e principais projetos como **Desenvolvedora Full Stack**. A aplicação foi arquitetada com foco em performance, código tipado, experiência do usuário (UX) fluida e microinterações visuais modernas.

---

## 🚀 Destaques e Recursos

- 🧩 **Arquitetura Componentizada & Tipada:** Construído com **React** e **TypeScript**, garantindo previsibilidade, segurança de tipos e componentes altamente reutilizáveis.
- ✨ **Animações 3D & Microinterações:** Transições suaves, efeitos de profundidade 3D e animações de entrada sincronizadas com o scroll utilizando **Framer Motion**.
- 🔍 **Filtros Dinâmicos de Projetos:** Categorização interativa para explorar os projetos por tecnologias, tipo de aplicação ou área de foco.
- 📬 **Formulário de Contato Funcional:** Integração real para envio direto de mensagens e propostas comerciais pela própria interface, com validação de campos e feedback visual.
- 📐 **Design Responsivo:** Estilização utilitária com **Tailwind CSS**, assegurando adaptação fiel desde dispositivos móveis até monitores ultrawide.
- 🚀 **Deploy Contínuo (CI/CD):** Hospedado na **Vercel** com atualizações automáticas a cada novo push no repositório.

---

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/):** Biblioteca principal para construção da interface de usuário e gerenciamento de estado.
- **[TypeScript](https://www.typescriptlang.org/):** Superset JavaScript para tipagem estática, interfaces e maior manutenibilidade do código.
- **[Tailwind CSS](https://tailwindcss.com/):** Framework CSS utility-first para estilização ágil, consistente e responsiva.
- **[Framer Motion](https://www.framer.com/motion/):** Biblioteca declarativa para animações fluidas, gestos e transformações 3D.
- **[Vite](https://vitejs.dev/):** Build tool e servidor de desenvolvimento de alta velocidade.
- **[Vercel](https://vercel.com/):** Plataforma de hospedagem e deploy contínuo.
- **[Git & GitHub](https://github.com/):** Controle de versão do código.

## 🔧 Como Executar o Projeto Localmente

### Pré-requisitos
- Node.js instalado (versão 18 ou superior)
- Gerenciador de pacotes `npm` ou `yarn`

### Passo a passo

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/NatiPeralta/portfolio-np.git]

2. **Acesse a pasta do projeto:**
   ```bash
   cd portfolio-np

3. **Instale as dependências:**
  ```bash
  npm install
  ```

4. **Configure as variáveis de ambiente (se aplicável):**
Caso utilize chaves de API para o serviço de envio de e-mail do formulário de contato, crie um arquivo .env na raiz baseado no .env.example e preencha suas credenciais.

5. **Inicie o servidor de desenvolvimento:**
  ```bash
  npm run dev
  ```
  
6. **Abra o navegador no endereço exibido no terminal (geralmente http://localhost:5173)**
